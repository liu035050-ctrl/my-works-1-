## 项目一：电商用户价值分层与精准营销策略

### 项目背景
某电商平台积累了海量用户交易数据，但运营团队在做促销活动时缺乏精准的人群定向能力——活动对象模糊、策略凭经验制定、效果无法追踪。本次分析旨在通过用户分层，识别不同价值群体的特征差异，为差异化营销策略提供数据依据。

### 项目目标
- 构建用户价值分层模型，识别核心用户群体
- 设计并验证营销策略的有效性
- 输出可落地的分层运营建议

### 数据概况
- 数据来源：电商平台用户交易数据集
- 数据规模：数万条用户交易记录
- 核心字段：用户ID、最近登录时间、购买频率、消费金额、优惠券使用记录

### 分析方法
1. **数据清洗**：使用 Pandas 完成去重、缺失值填充、异常值识别，清洗准确率达 98%+
2. **RFM用户分层**：构建最近购买时间、购买频率、消费金额三大指标，采用等频分箱法进行5分割打分，划分重要价值用户、潜力用户、流失用户等群体
3. **AB实验设计**：对潜力用户设计实验组/对照组，实验组发放满减券，通过 T 检验验证复购率提升显著（p < 0.05），策略被运营团队采纳并上线
4. **分层稳定性验证**：使用 MySQL 窗口函数计算复购率、30天留存率，验证分层结果可靠性

### 核心发现
- 25–35岁女性为核心消费群体，浏览时长与下单率呈强正相关（相关系数0.8+）
- AB实验组复购率显著高于对照组（p < 0.05）
- 分层结果在复购率、留存率指标上表现一致，稳定性可靠

### 项目产出
- 用户画像图表（年龄/性别/地域分布）
- RFM分层占比图
- 含分层结果及精准营销建议的完整分析报告
- 可复用的Python分析模板

### 技术栈
Python、Pandas、Matplotlib、MySQL、AB实验、T检验、RFM模型
